Alexander OS V13.3

Что изменено:
- на главной по умолчанию большая карточка показывает общий капитал;
- левая компактная карточка показывает цель дохода;
- правая компактная карточка показывает финансовую подушку;
- в Настройки -> Главная страница можно самостоятельно менять расположение трёх финансовых показателей;
- в Настройки -> Финансы и цели можно задавать цель дохода отдельно по месяцам;
- фактический доход рассчитывается автоматически из операций типа «Доход» за соответствующий месяц;
- из быстрого расхода удалены поле распознавания и кнопка «Распознать»;
- из редактора своей категории удалены ненужные поля распознавания.

Установка на GitHub Pages:
1. Удалить старые файлы из корня репозитория.
2. Загрузить содержимое этого архива в корень репозитория.
3. Выполнить Commit changes.
4. Дождаться успешного Pages deployment.
5. Полностью закрыть установленное приложение на iPhone и открыть снова.
