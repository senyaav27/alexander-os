Alexander OS V13.0

1. Удалите старые файлы из корня GitHub Pages.
2. Загрузите все файлы из этого архива.
3. Дождитесь публикации GitHub Pages.
4. Полностью закройте приложение на iPhone и откройте снова.

Ключевые изменения:
- отдельная настоящая тема «Чёрная»;
- на главной финансовая подушка берётся только из счетов с назначением «Финансовая подушка» или названием «Подушка»;
- единая система цветов и контрастов для всех пяти тем;
- уникальные имена CSS/JS и новый service worker исключают загрузку V12.8 из старого кэша.
