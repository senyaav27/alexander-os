Alexander OS V13.4

Готовая PWA-сборка для GitHub Pages.

Новое:
- добавлен стартовый экран загрузки на чёрном фоне;
- логотип появляется сразу, без пустого белого/чёрного экрана;
- экран скрывается после загрузки приложения;
- сохранены исправления финансового учёта из V13.3.

Как установить:
1. Удалите старые файлы из корня репозитория.
2. Загрузите содержимое архива, не сам ZIP.
3. Дождитесь GitHub Pages deploy.
4. Полностью закройте приложение на iPhone и откройте снова.
