Alexander OS — 15.8.5 (автосинхронизация и безопасное удаление)

ВНИМАНИЕ: перед заменой экспортируйте полную резервную копию JSON из Alexander OS.

Установка:
1. Распакуйте архив.
2. На GitHub откройте senyaav27/alexander-os.
3. В корень репозитория загрузите brand-sheets.js, заменив существующий файл.
4. Нажмите Commit changes и дождитесь обновления GitHub Pages.
5. Откройте приложение, убедитесь, что версия 15.8.5-auto-sync-hourly-safe-delete.
6. Если Google требует входа, нажмите «Войти через Google».
7. Создайте тестовый расход, дождитесь появления в AOS_Операции. Затем удалите расход через приложение (перемещение в корзину), проверьте исчезновение из таблицы без кнопки «Обновить сейчас».

Что изменено:
- Отправка после добавления, изменения и удаления через корзину (примерно 1 секунда после сохранения, плюс время Google API).
- Дополнительная проверка каждый час, когда приложение активно.
- Проверка при возвращении в приложение и восстановлении интернета.
- Удаление строк Google разрешается автоматически только при подтверждённой записи в корзине приложения, с ограничением объёма. При подозрительном исчезновении данных синхронизация останавливается.
- Защита от пропуска изменений, сделанных во время текущей синхронизации.

Ограничения:
- Статическое приложение на GitHub Pages не может гарантировать фоновую синхронизацию при закрытом iPhone.
- После истечения OAuth-токена может потребоваться повторный вход Google.
- Это односторонняя синхронизация Alexander OS -> Google Sheets. Ручные правки в таблице не загружаются в приложение.
- Удаления, сделанные до установки, без записи в корзине могут потребовать подтверждения.

Не загружайте ZIP целиком на GitHub: загрузите только распакованный brand-sheets.js.
