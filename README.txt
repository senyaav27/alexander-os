Alexander OS V12.7 - сборка для GitHub Pages

Что исправлено:
- Исправлена основная причина тормозов в форме быстрого расхода.
- Скрытые блоки теперь действительно скрыты и не занимают место.
- Редактор своей категории открывается только после нажатия.
- Список пользовательских категорий открывается только по команде.
- Модальное окно использует один независимый вертикальный скролл.
- Шапка и кнопки сохранения не перерисовываются при каждом движении.
- На iPhone отключены тяжёлые стеклянные blur-слои, но сохранён тёмный премиальный дизайн.
- Убраны принудительные фокусы полей, вызывавшие скачки интерфейса и клавиатуры.
- Горизонтальный выход за экран закрыт без постоянной записи scrollLeft.
- Логика плавающей кнопки больше не пересчитывает всю страницу при каждом пикселе скролла.

Как обновить:
1. Загрузи все файлы из архива в корень GitHub Pages с заменой.
2. Дождись завершения публикации.
3. Полностью закрой Alexander OS на iPhone и открой снова.

Данные localStorage сохраняются, если адрес GitHub Pages не меняется.
