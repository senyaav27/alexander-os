Alexander OS: автоматическое исправление синхронизации Google Sheets (23.10.2026)

ВАЖНО: прежде чем закрывать установленное приложение на iPhone, сделай экспорт полной резервной копии JSON. Не удаляй PWA, не очищай данные браузера. Не добавляй повторно расход 35 000 ₽.

Почему сейчас не работает:
- В Google Таблицу уходят старые 440 операций, новые остаются в интерфейсе.
- Код в main репозитория ещё НЕ содержит предыдущий hotfix.
- При отказе localStorage старое приложение может молча продолжить работать во временной памяти. Патч исправляет это и делает статус ошибки видимым.

УСТАНОВКА: 2 служебных файла + 1 запуск Actions
1. Распакуй архив.
2. Добавь в https://github.com/senyaav27/alexander-os следующие ДВА файла с точным сохранением путей:
   .github/workflows/aos-sheets-auto-fix.yml
   scripts/apply_sync_hotfix.py
   Загрузи их в репозиторий, затем сохрани коммит. НЕЛЬЗЯ размещать три файла только в корне.
3. На GitHub открой Actions > Install Alexander OS Sheets sync hotfix > Run workflow (ветка main).
4. После зелёного статуса workflow изменения app.js, brand-sheets.js, index.html, sw.js автоматически запишутся в main.
5. Если ошибку «Resource not accessible by integration» покажет уже GitHub Actions, зайди Settings > Actions > General > Workflow permissions и установи Read and write permissions, затем запусти workflow заново.
6. Учти: GitHub Pages может не обновиться от коммита, сделанного через GITHUB_TOKEN. Проверь Settings > Pages и при необходимости запусти публикацию вручную (если GitHub Pages уже публикуется через существующий workflow, запусти его заново).
7. При открытии Alexander OS убедись, что iPhone получил свежую версию сайта; вход в Google может потребоваться повторно.
8. Нажми «Обновить сейчас». Если расход на 35 000 ₽ ещё в открытой сессии приложения, он должен попасть в Google Sheets; иначе восстанови его из резервной копии (не вводи дубликат).
9. Проверь лист AOS_Операции в Google Sheets и количество записей.

ОГРАНИЧЕНИЯ:
- Патч НЕ записан мной напрямую в GitHub: у подключения ChatGPT нет права записи (403).
- Пользовательские финансовые данные не добавляются в GitHub.
- Патч не исправляет синхронизацию между несколькими устройствами и не работает при закрытом приложении.
- Если старая версия потеряла ещё не сохранённые изменения, автоматическое восстановление невозможно без резервной копии.
- Автоматические тесты проверяют логику на модели данных, а не поведение на конкретном iPhone.
