Alexander OS - исправление синхронизации Google Sheets

ПОЧЕМУ НУЖЕН HOTFIX
В текущем app.js ошибка записи в localStorage замалчивается: данные показываются из живой памяти,
а brand-sheets.js читает устаревшую копию localStorage и пишет «Синхронизировано».
Возможная причина - переполнение памяти из-за копий истории. Патч убирает расхождение,
пытается восстановить устойчивое сохранение и выводит предупреждение, если оно всё ещё не работает.

ВАЖНО: ПЕРЕД ПЕРЕЗАПУСКОМ ПРИЛОЖЕНИЯ
Экспортируйте полную резервную копию JSON из Alexander OS, пока недавние операции видны на экране.
Не удаляйте приложение. Не очищайте Safari/данные сайта.

ИНСТАЛЛЯЦИЯ С GITHUB НА IPHONE
1. Распакуйте этот ZIP.
2. Загрузите файлы scripts/apply_sync_hotfix.py и .github/workflows/aos-sheets-hotfix.yml
   в соответствующие пути репозитория senyaav27/alexander-os. Не перезаписывайте исходные app.js.
3. В GitHub: Actions -> Prepare Alexander OS Sheets hotfix -> Run workflow.
4. После успешного запуска скачайте artifact «Alexander-OS-Sheets-FIXED-files».
5. Замените на GitHub 4 полученных файла: app.js, brand-sheets.js, index.html, sw.js.
6. Убедитесь, что GitHub Pages успешно опубликовал обновление. Откройте Alexander OS.
7. Авторизуйтесь в Google, добавьте ТЕСТОВЫЙ расход 10 ₽ и проверьте, что число операций выросло.
8. Затем удалите тест и проверьте, что число и остаток восстановились.

АЛЬТЕРНАТИВА НА КОМПЬЮТЕРЕ
В checkout репозитория поместите scripts/apply_sync_hotfix.py, выполните
python3 scripts/apply_sync_hotfix.py
node --check app.js && node --check brand-sheets.js
После проверки сделайте commit и push четырёх файлов.

ПАТЧ НЕ ИЗМЕНЯЕТ КЛИЕНТСКИЕ ДАННЫЕ ИЛИ GOOGLE-ТАБЛИЦУ ПРИ УСТАНОВКЕ.
В случае нехватки localStorage при сохранении в приложении сначала пытается
сократить ТОЛЬКО устаревшие записи истории отмены (не операции, не счета и не заметки).
Если и это не поможет, данные могут остаться временными: будет явное предупреждение.

ЗАМЕТКИ
- Синхронизация по-прежнему работает только при открытом приложении и OAuth-доступе.
- Это защитный hotfix, а не полноценная синхронизация облачной базы/нескольких устройств.
- Нельзя гарантировать исправление iPhone до фактического теста на устройстве.
