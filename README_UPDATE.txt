Alexander OS V15.8 - недельные цели и фокус дня
=================================================

ДЛЯ УСТАНОВКИ
1. Сохрани резервную копию данных через существующий экспорт Alexander OS перед обновлением.
2. Распакуй ZIP.
3. Зайди в https://github.com/senyaav27/alexander-os.
4. GitHub -> Add file -> Upload files. Перенеси из архива четыре файла в КОРЕНЬ текущего репозитория:
   app.js             - ЗАМЕНИТЬ
   index.html         - ЗАМЕНИТЬ
   sw.js              - ЗАМЕНИТЬ
   tasks-weekly.css   - ДОБАВИТЬ
5. Подтверди Commit changes, дождись публикации GitHub Pages.
6. Полностью закрой PWA Alexander OS на iPhone и открой снова. Очистка данных сайта НЕ нужна.

ИЗМЕНЕНО ТОЛЬКО В РАЗДЕЛЕ «ЗАДАЧИ»
- Недельные цели (не более 3), переход между неделями, отметка результата.
- Статистика задач выбранной недели и связанных с каждой целью задач.
- Карточка «Фокус дня» с главной задачей и счётчиком активных дел.
- Отметка главной задачи дня, одна на дату.
- Для новых/переносимых на дату активных задач лимит 3 в день; ранее существовавшие не удаляются.
- Связь задачи с недельной целью через форму задачи.
- Перенос задачи с обязательным указанием причины и записью истории переносов.
- Сохранение целей внутри основного состояния Alexander OS (в существующий localStorage и резервную копию).

НЕ ИЗМЕНЯЛОСЬ
- Логика финансов, проектов, привычек, заметок, графиков и существующих операций.
- Остальные CSS/JS и изображения; исходные пользовательские записи не удаляются.

ПРОВЕРКИ
- Node.js: синтаксис app.js и sw.js корректен.
- Chromium: добавление/редактирование/выполнение цели, недельная навигация,
  ограничение в 3 цели, назначение главной задачи, привязка цели к задаче,
  перенос с причиной, обязательность причины - успешно.
- Сохранение и повторное чтение структуры состояния - успешно в тестовой среде с имитацией localStorage.
- Полный end-to-end на реальном GitHub Pages и iPhone PWA выполнить здесь нельзя.

ВАЖНО
- Данные Alexander OS сейчас хранятся на устройстве в локальном хранилище браузера.
  Это обновление не добавляет синхронизацию между телефоном и компьютером.
- Не заливай весь старый архив V14/V15: загрузи только эти 4 файла.
