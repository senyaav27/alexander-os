# Alexander OS V15.5 - QA

## Архитектура

- Build: `15.5.0`
- `senyaav-ai-v155.js` загружается ДО `app.js`, поэтому может фиксировать новые изменения состояния через `localStorage.setItem`.
- SENYAAV AI не использует `MutationObserver` и не запускает фоновые циклы перерисовки.
- Единственный UI enhancement вызывается из существующего лёгкого scheduler в `runtime-v155.js`.
- Старые `motion-v15.js`, `finance-v151.js`, `features-v152.js` не подключаются.
- Навигационные анимации не возвращены. Сохраняется только однократное заполнение progress-bar Главной при холодном запуске.

## Проверка отсутствия повторов

- Главная сохраняет единственное приветствие Alexander OS.
- Карточка SENYAAV AI не использует `Доброе утро, Александр`.
- В Финансах отдельная вторая AI-карточка не создаётся: существующий блок `Выводы` превращается в `SENYAAV AI - Финансы`.
- На Задачах, Проектах и Прогрессе создаётся максимум один контекстный AI-блок на экран.

## Ограничение тестовой среды

Chromium установлен, но политика среды блокирует открытие и `http://127.0.0.1`, и `file://` (`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому полноценный Playwright screenshot/E2E именно здесь выполнить нельзя. Вместо этого выполнены синтаксические, структурные и VM-тесты логики состояния.

## Важное продуктовое ограничение Preview

Это локальный аналитический слой, а не LLM. Он умеет читать данные и отвечать на типовые вопросы по правилам. Для настоящего свободного диалога позже нужен OpenAI API через серверный endpoint. API-ключ нельзя помещать в GitHub Pages/frontend.
