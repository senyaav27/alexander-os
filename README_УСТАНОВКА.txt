Alexander OS V16.0 - BLACK/LIME DESIGN
Основа: текущая ветка main из senyaav27/alexander-os, UI V15.8.

Внутри архива готовые:
  brand-theme.css                  НОВЫЙ дизайн для ВСЕХ тем
  tools/install-v16.mjs            безопасно правит текущие app/index/sw/manifest
  tools/verify-v16.mjs             автоматическая проверка
  .github/workflows/install-alexander-v16.yml

УСТАНОВКА
1. До обновления: в Alexander OS Настройки -> Экспорт JSON, сделай резервную копию.
2. В Settings -> Actions -> General -> Workflow permissions выбери Read and write permissions.
   В Settings -> Pages -> Source выбери GitHub Actions.
3. Разархивируй ZIP локально. В корень GitHub репозитория загрузи:
   - brand-theme.css (с заменой существующего)
   - папку tools/ с двумя .mjs
   - .github/workflows/install-alexander-v16.yml
   Важно: загружать СОДЕРЖИМОЕ ZIP, не сам .zip файл.
4. GitHub Actions -> Install and deploy Alexander OS V16 -> Run workflow.
   Workflow выполнит замену версии, кеша, исправление аналитики, commit и deploy.
5. Дождись успешной публикации GitHub Pages. Старая ветка main не перезаписывается до прохождения тестов.
6. Запусти установленную PWA (НЕ удаляй её и НЕ чисти site data/localStorage) и в настройках
   выбери тему Чёрная/Black для изображения как в референсе.
7. Проверь Главная -> Финансы -> Задачи -> Проекты -> Прогресс, создание тестовой операции,
   редактирование и удаление тестовой операции, баланс счета, клавиатуру/модальное окно и цвет тем.

ИЗМЕНЕНИЯ
- ПЕРЕПИСАН brand-theme.css: старый безусловно назначал БЕЛЫЙ фон ВСЕМ темам, даже чёрной.
- Чёрный #000, карточки #0D0E0E и #151717, текст #FAFCFA, лайм #B9FD50.
- Тёмная и светлая темы разделены. Другие темы сохранены в близких цветах.
- Иконки и нижнее меню: 5 одинаковых колонок, высота и выравнивание под iPhone.
- Адаптация форм и модалок, размер поля >=16px, safe areas, отсутствие горизонтального скролла.
- Главная: ряд из 4 быстрых кнопок Добавить / Счета / Платежи / Аналитика.
  Счета вместо Перевод: текущая V15.8 не имеет надёжной функции перевода.
  Кнопка должна вести на работающий экран, а не изображать функцию.
- Меньше размытия и анимаций для плавной прокрутки.
- finance.freeBalance перестал считать подушку как свободные деньги.
- Ошибочные analytics.free ссылки заменены на analytics.freeBalance.
- PWA cache/manifest/build label -> V16.0; схема хранения данных 14.3 НЕ менялась.

ОГРАНИЧЕНИЯ
- GitHub connector разрешает чтение, но создание веток получает 403. Поэтому изменения
  не залиты от имени ChatGPT, а переданы в виде установочного ZIP.
- Референс iPhone - образец композиции и палитры; системные элементы iOS не копируются.
- Видеопроверка: в iPhone Safari есть свидетельства светлых карточек в чёрной теме,
  нечитабельного текста и перекрытий; базовые причины устранены в CSS.
- До публикации выполнить резервную копию через существующий экспорт данных.
- Не проводилось проверок реального iOS Safari после деплоя, полная оценка 10/10 пока недоказуема.
- Если в репозитории уже другая версия/структура файлов, инсталлятор остановится
  вместо рискованной перезаписи данных.
