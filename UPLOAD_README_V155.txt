Alexander OS V15.5 - SENYAAV AI Preview

ЗАГРУЗКА
1. Распакуй ZIP.
2. Загрузи все файлы из архива в корень репозитория senyaav27/alexander-os.
3. Файлы с тем же именем GitHub обновит. Старые файлы удалять не требуется.
4. После деплоя полностью закрой PWA на iPhone и открой заново.
5. В шапке должна быть версия V15.5.

ФАЙЛЫ
- index.html - обновлённый build и подключения.
- sw.js - новый cache V15.5.
- runtime-v155.js - текущая логика V15.4 + исправление Plan/Fact + hook SENYAAV AI.
- motion-v155.css - прежняя политика: никаких повторных анимаций после запуска.
- senyaav-ai-v155.js - локальный анализ, журнал действий, UI SENYAAV AI.
- senyaav-ai-v155.css - дизайн SENYAAV AI.
- QA_REPORT_V155.md - результаты проверки.

ВАЖНО
SENYAAV AI Preview сейчас не использует OpenAI API. Он анализирует локальные данные Alexander OS по правилам.
Журнал точных действий начинает накапливаться с момента установки V15.5. Старые действия до V15.5 нельзя восстановить задним числом с точным временем, если в данных не было createdAt/date.
